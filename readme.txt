# 🗨️ Open Chatbot AI

This is a simple chatbot project powered by the **OpenAI API**.  
You can host it yourself, customize the code, and connect it with your own OpenAI account.

---

## ⚙️ Requirements
- Node.js (latest LTS recommended)
- npm or yarn package manager
- An OpenAI API key (you must generate your own)

---

## 🔑 Setup Instructions

1. **Clone or download** this project folder.  
2. **Install dependencies**:
   ```bash
   npm install

Create a .env file in the root directory.
Add your OpenAI API key and base URL like this:

OPENAI_API_KEY=your_api_key_here
OPENAI_API_URL=https://api.openai.com/v1

Save the .env file.

Run the chatbot:

npm start

🌐 Hosting
You can host this chatbot on your own server, cloud provider (e.g., AWS, Heroku, Vercel), or locally.

No domain is required, but adding one makes your project more professional.

🛠️ Customization
All source code is included in this folder.

You are free to modify prompts, UI, or logic to suit your needs.

The chatbot is designed to be flexible and developer-friendly.
